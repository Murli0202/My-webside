HTML, in a nutshell

HTML is the language that gives a web page its meaning and structure. Tags wrap around content to describe what it is.

<p>A paragraph goes here.</p>
✳

CSS, in a nutshell

CSS is the language that styles a web page. A rule selects an element, then sets the way it should look.

p { color: rebeccapurple; }
