# HTML + CSS for Beginners

A small learning site with separate pages:

- `index.html` — start here
- `html.html` — HTML basics
- `css.html` — CSS basics
- `test.html` — edit code and preview it
- `style.css` — shared page styles
- `script.js` — makes the tester work

Open `index.html` in a browser to begin. You can edit the example code on the Try it page and press **Show my page**.
